# 🎓 Student Hub Portal

## 📌 Project Overview
Student Hub is a simple HTML5-based website designed for students to access academic information, register, log in, view their profile, participate in events, submit feedback, and contact the administration.

This project demonstrates the use of **HTML5 Semantic Elements** to create a well-structured and user-friendly website.

---

## ✨ Features

- Home Page
- About Page
- Student Registration
- Student Login
- Student Dashboard
- Student Profile
- Events Information
- Feedback Form
- Frequently Asked Questions (FAQ)
- Contact Page
- Admin Panel

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the **Student Hub** folder.
3. Double-click **index.html** or open it in any web browser.
4. Use the navigation links to visit other pages.
